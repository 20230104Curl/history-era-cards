# 高校受験 同時代史攻略

中３社会の同時代史トレーニング。選定済みの世界史30項目・日本史50項目を収録する。

## 使い方

起動時は年表を表示する。上部の大きな「年表」「暗記カード」「テスト」ボタンで画面を切り替える。

- 暗記カード：日本史／世界史を選び、年号カードをタッチして出来事を表示する。「覚えた」「もう一度」で記録し、次のカードへ進む。年代順・シャッフル・状態による絞り込み・任意カードへの移動に対応。
- 同時代テスト：世界史→日本史、日本史→世界史、ランダムの３モード。３問・６問・10問の３段階。年号は解答後に表示する。４枚の中で最も年代が近い出来事を選ぶ。
- 年表：左に日本史、中央に西暦、右に世界史を配置する。同じ年の出来事は左右同じ行に並べる。検索・タッチで暗記への移動に対応。年表は全収録範囲を通してページ送りする。
- 学習記録は端末・ブラウザのlocalStorageに保存する。端末間同期・教師への成績送信は実装していない。

## 段階ごとの出題

`dist/engine.js` で生成する。データは `dist/data.js` に集約し、今回の変更では内容・ID・80項目の数を変更していない。

- ３問・６問（near）：その問題文の出来事に対して、全教材内で年代が最も近い反対側の出来事を正解として含める。同じ最短距離の相手が複数あれば、いずれかを選ぶ。全80項目を問題文に使える。
- 10問（transfer）：その最短距離の相手を、正解・誤答の両方から除外する。残った教材から条件に合う正解候補を変えて選び、その４択で最も近いものを答える。常に同じ２番手を選ばせる方式にはしない。
- フランス革命（1789）→寛政の改革（1787）、および逆方向は、３問・６問で含め、10問では選択肢から外す。
- 両段階で同じ正解距離の上限・誤答との余裕を適用する。除外後に無理なく出せる正解がない項目は10問の問題文から外す。現行教材では71項目（世界29・日本42）が10問の問題文として使える。年表・暗記カードは80項目のまま。
- 問題文・正解・誤答の年号を10年区切りの範囲へ広げても、正解の最悪距離より誤答の最良距離が十分大きい組合せだけを採用する。１年単位の差で正誤が入れ替わる選択肢は出さない。
- 同じテスト内で問題文を重複させない。ランダムは両方向をほぼ同数にする。

`nearestPartners` が最短の相手、`BLUEPRINTS_BY_LEVEL` が段階別の出題候補、`buildSession` が３・６・10問のセッションを作る。

## 満点クリアと学習記録

各段階で３つのモードをそれぞれ満点にすると、次の段階へ進む。

- ３問の３モード満点で、スタンプ３つと６問挑戦券を獲得する。
- ６問の３モード満点で、バッジ３つと10問挑戦券を獲得する。
- 10問の３モード満点で、トロフィー３つと完全クリアになる。
- 同じモードの再クリアは重複計上しない。１問でも間違えた回・途中終了・誤答だけの復習では印を増やさない。
- 画面と開始処理の両方で未解放段階を制限する。再読み込みで満点記録を復元する。

`dist/rewards.js` の新しい保存形式は `rewards.version: 3`。旧 `version: 2` の５・10・15問の満点記録は、段階順に３・６・10問へ引き継ぐ。旧10問の記録を新しい最終10問へ誤って移さない。下位段階が未達の場合、上位だけの不整合な記録を採用しない。暗記記録・過去のテスト履歴も保持する。満点の根拠がないさらに古い完走報酬は、従来どおり進級に使わない。

## 色と獲得演出

３問は青、６問は紫、10問は金色。設定・出題・結果・満点記録に同じ段階の色を使う。印の数字も３・６・10にそろえる。

新しい満点獲得では印を押す短いアニメーション・波紋・光の粒を表示し、最新の印を３モードの獲得欄に追加する。３モード達成時は大きなCLEAR表示と挑戦券、最後はALL CLEARとトロフィー３つを表示する。結果を見返すとき・再クリア・復習・未クリアでは新規獲得演出を再生しない。端末の「動きを減らす」設定を尊重し、演出中も操作できる。

## スクロールなしのタッチ操作

画面の高さに合わせて暗記・設定・出題・結果・記録を配置し、ボタンを画面内に保つ。主なタッチ領域は44px以上。

- 年表・暗記のカード選択は、表示領域に合わせて行数や枚数を決め「前へ」「次へ」で切り替える。検索条件の変更時は先頭ページへ戻る。
- テストは４枚の選択肢、解答後の丸と年号、次へ進むボタンを同じ画面に表示する。
- 解答の振り返りは１問ずつ切り替える。再挑戦・誤答復習は「結果」から操作する。
- 満点の記録は３・６・10問を切り替えて確認する。
- 縦横変更と検索キーボードによる可視領域の変化に追従し、検索フォーカスを保つ。

## 検証・配信

`npm test` で教材保持、全候補の公平性、段階別の相手の包含・除外、３方向の出題と重複防止、満点進級、記録移行、獲得演出の条件を検証する。

静的サイトとして `dist/` を配信。追加依存なし。日本語・数字ともに端末のフォントで動作する。

## 年表と語呂付きカード

`dist/timeline.js` で80項目を77の西暦の行にまとめる。1543・1600・1853年は日本と世界の出来事を同じ行に表示する。年の間隔は均等な行として表示し、近い出来事を固定ペアとして結びつけない。片側の出来事で検索しても、同じ年の反対側は保持する。重複行をなくし、実際の文章の高さに合わせて各ページへ詰める。短い見出しからカードへ移ると元の出来事を確認できる。縦横変更時は表示中の年付近を維持する。

`dist/mnemonics.js` に全80項目の語呂、読みと数字の対応、参考元または作例の区別を収録する。元の教材データ・IDは変更しない。カードの年号面に語呂と読みを添え、裏面はこれまでどおり出来事を表示する。調べた短い語呂を参考に教材の表現に合わせて調整し、独自に組み立てた文は「作例」とする。カード下部に小さな灰色の出典名を表示する。生徒用画面には外部サイトへ移動するリンクを置かない。語呂の文は記憶用の表現であり、そのまま史実の説明として扱わない。

参考語呂の調査先は `MNEMONIC_SOURCES` に集約した複数の塾・年号資料。935年の挙兵と939年の新皇、1519年の出発と1522年の船隊による世界一周など、別の出来事・年号の語呂を取り違えない。テスト画面には語呂を表示しない。

`tests/study.test.mjs` で80語呂と年号の対応、77行への集約、同年の左右保持、年代検索、重複のないページ送りと全項目への到達を検証する。

年表をブラウザで全ページ送りし80項目へ到達することを確認した。1543年の左右同年表示、検索・該当なし、年表からカードへの移動、長文の語呂・裏面、テストでの語呂非表示も確認。1024×600、1280×720、768×1024、390×700でページや操作ボタンにはみ出しがないことを確認した。

## 視認性の調整と語呂イラスト

- 年表は最大880pxの幅に中央配置。日本史は右寄せ、世界史は左寄せにして、西暦へ視線を集める。通常のタブレット横画面は22ptを基準とし、小画面では収まる大きさへ調整する。
- `TIMELINE_LABELS` の短い見出しを使い、全文はカードで確認できる。全文でも見出しでも検索でき、同年の反対側を保持する。
- `paginateTimeline` は描画時に実測した行の高さを使い、各ページへ重複なしで詰める。１つの長文に合わせて全行を大きくしない。
- カードの年号はタブレットで60〜82px程度を確保し、語呂の主要部分も32〜44px程度の吹き出しで強調する。数字を補助扱いにせず、語呂と両方を読ませる。
- `dist/art/` に80項目それぞれの語呂から連想したアニメ調イラストをWebPで収録し、`dist/illustrations.js` で画像・語呂の主要部分・代替説明を対応づける。画像内の文字を避け、吹き出し文字は通常のHTMLとして鮮明に表示する。これらの絵は語呂の記憶用の連想であり、史実を再現した絵ではない。
- イラスト付きカードもタッチで出来事へ反転でき、既存の暗記記録・テスト条件は維持する。

今回のブラウザ確認：1024×600では年表26ページ→14ページ、1280×720では19ページ→11ページ。1024×600で全14ページを送り、重複なく80項目へ到達し、長文にもはみ出しがないことを確認。390×700で暗記カード全80枚の年号・語呂・イラスト・操作ボタンが画面内に収まることを確認。768×1024、1280×720でもレイアウト・反転・テスト画面での語呂とイラストの非表示を確認。

メニューは左から「年表」「暗記カード」「テスト」。年表の年代範囲セレクターを外し、通常は375〜1867年の全80項目を一続きのページ送りで表示する。検索だけは必要に応じて使える。

## アニメ調カード

承認済み３枚の試作と同じ方向で、80項目すべてに専用のアニメ調画像を生成した。人物の表情・動き・語呂に結びつく道具を場面として描く。画像には文字を焼き込まず、年号・語呂・数字の読みを通常のHTMLとして重ねずに隣接配置し、端末でも鮮明さを保つ。横画面は左に大きな絵、右に年号と語呂。小画面は上下に積む。裏面は元の出来事の全文を表示する。

画像はWebPへ圧縮し、現在の１枚と前後のカードだけを読み込む。全80枚を一度にダウンロードしない。生成プロンプトと各場面の説明は `docs/artwork-prompts.json` に記録する。服装や道具には語呂の連想用の創作表現を含む。史実の一次資料や正確な復元図として扱わない。年表・テスト・保存形式・教材の出来事と年号は変更しない。

`tests/illustrations.test.mjs` で全80画像の同梱、画像の重複がないこと、WebP形式と配信サイズ、語呂の維持を確認する。

アニメ版の確認：390×700で全80枚を１枚ずつ表示し、画像80枚すべての読み込み・重複なし・文字と操作ボタンのはみ出しなしを確認。1024×600、1280×720、768×1024では最長の語呂と代表カードを確認し、反転操作とテストでのヒント非表示も確認した。24件の自動検証がすべて成功。

## オフライン利用

各端末で最初の１回はネットへ接続し、公開URLをChrome・Edge・Safariなどの通常のブラウザで直接開く。画面下の「オフライン準備」をタッチし、「✓ オフライン利用可」になるまで待つ。約18MBの教材プログラム・年表・全80枚の画像を保存し、以後は同じブラウザのブックマークやホーム画面からネットなしで開ける。学習記録は従来どおり端末ごとのlocalStorage。ブラウザのサイトデータを削除した場合には、もう一度準備する。

`dist/sw.js` は全ファイルの保存成功後にだけ有効になり、通信がなくても自分の教材キャッシュから画面と画像を返す。新しい版の保存に失敗したときは、前の準備済み版を消さない。他のアプリのキャッシュや学習記録には触れない。`dist/offline.js` は進捗と保存状態を表示し、途中を利用可と表示しない。保存要求は同時に１つとし、画像は４並列で取得する。`manifest.webmanifest` は対応ブラウザのアプリ追加に使う。

**dist内を変更したら、必ず `npm run build:offline` を実行して `offline-assets.js` を更新してから検証・配信する。** ファイル内容から教材版の識別子を計算する。実行時のJS・CSS・HTML・画像をすべて収録し、バージョン付きのモジュールURLにも対応する。`tests/offline.test.mjs` で全資産の包含、ネットワークを拒否した状態での全教材の応答、失敗時の未完了判定と旧版保持、他アプリのキャッシュ保持を検証する。

配信先CDNから転送された応答も、そのまま転送付きで返さず、教材の同一URLで読み出せる応答として保存・配信する。これによりオフラインのページ再表示や相対モジュール参照がCDNのURLへ流れない。公開環境で95資産の全保存と「オフライン利用可」の表示を確認。再表示のブラウザ自動確認は環境のURLポリシーで制限されたため、実際の機内モードからの起動は利用端末で確認する。ネットワーク拒否とCDN転送付き応答を使う自動テストで再表示の応答条件を確認した。
